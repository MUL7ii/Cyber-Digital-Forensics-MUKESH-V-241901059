## Aim of Each Experiment

### Experiment 1 – Study of Computer Forensics and Different Tools Used for Forensic Investigation

- **Date:** 18-07-2026
- **Aim:** To study the field of computer (digital) forensics and to understand the different tools that are used during a forensic investigation.
- **Record:** [experiment-01.pdf](experiments/experiment-01.pdf)

### Experiment 2 – Introduction to Digital Forensics (TryHackMe)

- **Date:** 18-07-2026
- **Aim:** To understand the basics of digital forensics and the standard digital forensics process by completing the TryHackMe room “Intro to Digital Forensics”.
- **Record:** [experiment-02.pdf](experiments/experiment-02.pdf)

### Experiment 3 – Windows Forensics 1 (TryHackMe)

- **Date:** 23-07-2026
- **Aim:** To learn Windows registry forensics and to identify important Windows forensic artifacts by completing the TryHackMe room “Windows Forensics 1”.
- **Record:** [experiment-03.pdf](experiments/experiment-03.pdf)

### Experiment 4 – Live Forensics Case Investigation using Autopsy

- **Date:** 30-07-2026
- **Aim:** To perform a live forensic case investigation on a disk image using the Autopsy forensic platform and to generate a forensic report.
- **Record:** [experiment-04.pdf](experiments/experiment-04.pdf)

### Experiment 5 – Recover Deleted Files using Forensics Tools (FTK Imager)

- **Date:** 06-08-2026
- **Aim:** To recover a deleted file from a storage device by creating a forensically sound bit-by-bit image using FTK Imager, and to verify the integrity of the image using hash values.
- **Record:** [experiment-05.pdf](experiments/experiment-05.pdf)

### Experiment 6 – Find Last Connected USB on the System (USB Forensics)

- **Date:** 13-08-2026
- **Aim:** To identify the last connected USB device on the system using USBDeview.
- **Record:** [experiment-06.pdf](experiments/experiment-06.pdf)

### Experiment 7 – View Last Activity of Your PC

- **Date:** 20-08-2026
- **Aim:** To view the last activity performed on the system using the LastActivityView tool.
- **Record:** [experiment-07.pdf](experiments/experiment-07.pdf)

### Experiment 8 – Extraction of Browser Artifacts

- **Date:** 03-09-2026
- **Aim:** To extract browser artifacts such as the browsing history and cache from the system using browser forensic tools.
- **Record:** [experiment-08.pdf](experiments/experiment-08.pdf)

### Experiment 9 – Comparison of Two Files by Compare It Software

- **Date:** 10-09-2026
- **Aim:** To compare two files for forensic investigation using the Compare It software and to generate a differences report.
- **Record:** [experiment-09.pdf](experiments/experiment-09.pdf)

### Experiment 10 – Collecting Email Evidence in Victim PC

- **Date:** 17-09-2026
- **Aim:** To collect e-mail evidence from a victim’s PC by acquiring the physical memory and extracting the e-mail artifacts.
- **Record:** [experiment-10.pdf](experiments/experiment-10.pdf)

### Experiment 11 – Hiding and Extracting a Text File behind an Image / Audio File using Command Prompt

- **Date:** 24-09-2026
- **Aim:** To study the steps for hiding and extracting any text file behind an image file or an audio file using the Command Prompt.
- **Record:** [experiment-11.pdf](experiments/experiment-11.pdf)

### Experiment 12 – Extraction of EXIF Data from Image Files using ExifReader

- **Date:** 01-10-2026
- **Aim:** To extract the Exchangeable image file format (EXIF) data from an image file using the ExifReader software.
- **Record:** [experiment-12.pdf](experiments/experiment-12.pdf)
